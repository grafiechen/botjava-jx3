## 范围

当前工作区 Java/Spring Boot 源码、配置、Vue/HTML 图片模板、PostgreSQL/MongoDB 持久化、QQ/JX3API WebSocket 与 HTTP 边界。

## 结果

完成三轮人工静态审计，并对确认成立的问题直接修复。

1. 入站与权限：修复 QQ Hook/Webhook 仅验签但不校验时间新鲜度的问题，增加默认 300 秒时间窗；增加 1 MiB 原始请求体上限。检查 C2C 主号、群管理员、数据库授权、个人角色所有权与群隔离。
2. 网络与渲染：模板数据改用 Base64 UTF-8 JSON 注入，消除 `</script>` 大小写变体造成的脚本上下文逃逸；模板浏览器仅允许 `bot.local` classpath 资源，阻断公网 HTTP/HTTPS。检查远程图片 HTTPS 白名单、私网地址拒绝、禁止重定向、字节与像素限制。
3. 数据与资源：检查 JPA 参数化查询、MongoDB 等值过滤与字段白名单、反序列化、文件和进程调用；生成图片在上传完成后清理，避免长期运行磁盘积累。

没有保留已确认的高危或严重问题。剩余部署风险：进程级每秒 2 次限速在多实例下不是集群全局限速；生产多实例需要出口网关共享限流。
